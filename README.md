#👨🏻‍💻 Customer Behavior Analysis Dashboard

## Overview

This end-to-end data analytics project analyzes customer purchasing behavior to uncover spending patterns, subscription trends, product performance, and customer demographics. The project demonstrates the ability to translate raw data into strategic business intelligence by:

✅ Data Preparation,Modeling & Exploratory Data Analysis (Python): Clean and transform the raw dataset for analysis.

✅ Data Analysis (SQL): Simulate business transactions, and run queries to extract insights on customer segments, loyalty, and purchase drivers.

✅ Visualization & Insights (Power BI): Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

✅ Report and Presentation: Write a clear project report summarizing your key findings and business recommendations. Prepare a presentation that visually communicates insights and actionable recommendations to stakeholders.

The objective is to help businesses better understand customer behavior and identify opportunities to improve customer engagement, retention, and revenue generation.

---

## Business Problem

Retail businesses generate large volumes of customer transaction data but often struggle to convert this information into actionable insights.

This project aims to answer key business questions such as:

* Which customer segments generate the most revenue?
* Do subscription members spend more than non-subscribers?
* Which product categories perform best?
* How do customer demographics influence purchasing behavior?
* What is the impact of discounts and promotions on sales?

## Data Cleaning & Preparation

The following data preparation steps were performed:

### Missing Value Handling

* Identified 37 missing values in the Review Rating column.
* Filled missing ratings using the median review rating within each product category.

### Column Standardization

* Converted all column names to snake_case format.
* Removed special characters and spaces from column names.

### Feature Engineering

#### Age Group Segmentation

Created a new column:

* Young Adult
* Adult
* Middle-aged
* Senior

using quartile-based age segmentation.

#### Purchase Frequency Days

Converted textual purchase frequencies into numeric values for analysis:

| Frequency   | Days |
| ----------- | ---- |
| Weekly      | 7    |
| Fortnightly | 14   |
| Monthly     | 30   |
| Quarterly   | 90   |
| Annually    | 365  |

### Redundant Column Removal

* Removed `promo_code_used` because it contained identical information to `discount_applied`.

## SQL Business Analysis

The cleaned dataset was loaded into PostgreSQL for advanced querying.

Business questions answered using SQL:

1. Revenue generated by gender.
2. Customers spending above average while using discounts.
3. Top-rated products based on review ratings.
4. Purchase behavior by shipping method.
5. Subscriber vs non-subscriber spending comparison.
6. Products with the highest discount utilization.
7. Customer segmentation based on previous purchases.
8. Most purchased products by category.
9. Relationship between repeat buyers and subscription status.
10. Revenue contribution by age group.

Techniques used:

* Aggregations
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* CASE Statements
* Ranking Functions

* Young Adults generated the highest revenue.

* Outerwear contributed the lowest revenue.

* Non-subscribers represent the majority of customers.

* Average review rating remained relatively positive at 3.75/5.
